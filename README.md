# Problem Statement

## Objective
This assignment is designed to evaluate understanding of Git workflow, Pull Requests, and basic TypeScript coding practices.

## Task 1: Pull Request Template Setup
- Create a `.github` folder in the repository if it does not already exist
- Add a `pull_request_template.md` file inside the `.github` folder
- Configure the Pull Request template to include:
  - Problem statement
  - Solution overview
  - Testing done
  - Checklist (lint, build, tests)

## Task 2: Fibonacci Implementation in TypeScript
- Implement the Fibonacci series using TypeScript
- Ensure proper TypeScript typing
- Handle edge cases such as:
  - `n = 0`
  - `n = 1`
- Write clean, readable, and maintainable code
- Create a Pull Request using the template defined in Task 1
